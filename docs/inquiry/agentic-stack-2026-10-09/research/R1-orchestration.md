## 2. Claim verification

1. **Paperclip ~99,000 stars, MIT; plugin SDK "alpha" — CONFIRMED.** 99.1k stars and MIT ([repo](https://github.com/paperclipai/paperclip), 2026-10-09). SDK page: "The plugin runtime is in alpha. The SDK still ships breaking changes between Paperclip releases" ([SDK](https://docs.paperclip.ing/reference/plugins/sdk), 2026-10-09). The README roadmap marks the plugin *system* complete; the alpha label applies to runtime/SDK stability.
2. **Issues #2743, #3317, #11597 — CONFIRMED as described; all OPEN on 2026-10-09.**
   - [#2743](https://github.com/paperclipai/paperclip/issues/2743) (model/adapter fallback on rate limit or budget): opened 2026-04-04; no labels or upstream PR; last activity a fork commit 2026-08-18.
   - [#3317](https://github.com/paperclipai/paperclip/issues/3317) (fallback on plan quota): opened 2026-04-10; one comment 2026-09-21.
   - [#11597](https://github.com/paperclipai/paperclip/issues/11597): parsed quota reset "is stored but never gates new run creation (160 of 400 runs burned…)", opened 2026-08-18 on Paperclip 2026.722.0; related PR #10616 does not close the core gap; independent report 2026-10-05.
   - Also relevant: [#2014](https://github.com/paperclipai/paperclip/issues/2014) (opt-in Claude→Codex fallback, opened 2026-03-28) and its fix [PR #9367](https://github.com/paperclipai/paperclip/pull/9367), open since 2026-07-10 with no maintainer review visible. No maintainer response appears on any of these.
3. **Anthropic help centre updated 2026-10-07; Max covers Agent SDK/`claude -p`/third-party usage; Max includes API credits — MOSTLY CONFIRMED, with material conditions.**
   - The [support article](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan) carries an "Update October 7, 2026": Max and Team plans "now include monthly API credits"; "You can still use the Claude Agent SDK, `claude -p`, and third-party apps with your subscription limits." The wording is "third-party apps", not "supported third-party usage"; it defines neither term nor which apps.
   - Credits: Max 5x $100, Max 20x $200, Team up to $500 pooled. Pro, Free and Enterprise are excluded. Credits are spent through a linked Console organisation's API key and cover the API, Managed Agents and Agent SDK, "Doesn't cover: Claude Code"; they expire monthly ([platform docs](https://platform.claude.com/docs/en/about-claude/api-credits-for-subscribers)). The support article also lists `claude -p` as covered, so Anthropic's two pages are slightly inconsistent.
   - **The binding restrictions still apply** ([legal and compliance](https://code.claude.com/docs/en/legal-and-compliance), read 2026-10-09). Consumer OAuth "is designed to support ordinary use of Claude Code and other native Anthropic applications". Third-party developers may not "offer Claude.ai login" or "route requests through Free, Pro, or Max plan credentials on behalf of their users". This does not stop "an end user from signing in to the unmodified Claude Code binary with their own Claude subscription". "Advertised usage limits for Pro and Max plans assume ordinary, individual usage of Claude Code and the Agent SDK." The [Consumer Terms](https://www.anthropic.com/legal/consumer-terms) (effective 2025-10-08) bar "automated or non-human means" except via API key "or where we otherwise explicitly permit it". They also bar sharing account credentials.
   - Volatility in 2026:
     - 2026-02-19: OAuth outside Claude Code/Claude.ai banned ([AlternativeTo](https://alternativeto.net/news/2026/2/anthropic-officially-bans-using-subscription-authentication-for-third-party-claude-use)).
     - 2026-04-04: "third-party harnesses including OpenClaw" moved to pay-as-you-go ([TechCrunch](https://techcrunch.com/2026/04/04/anthropic-says-claude-code-subscribers-will-need-to-pay-extra-for-openclaw-support/)).
     - 2026-05-13: separate Agent SDK credits announced for `claude -p`, GitHub Actions, OpenClaw and Conductor ([VentureBeat](https://venturebeat.com/technology/anthropic-reinstates-openclaw-and-third-party-agent-usage-on-claude-subscriptions-with-a-catch)).
     - 2026-06-15: that change was paused ([support article](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan)).
     - 2026-10-07: the credit was replaced by API credits.
   - **Practical reading:** an orchestrator on the user's own machine that spawns the unmodified `claude` binary under that user's login (Paperclip `claude_local`, Tutti) matches the explicitly tolerated pattern. Products that implement their own Claude OAuth, proxies that pool logins (CLIProxyAPI-style), and multi-account rotation conflict with the published rules. Heavy unattended fleets are exposed to the "ordinary, individual usage" clause.
4. **OpenAI permits Codex CLI via ChatGPT plans, including third-party/unattended use — CONFIRMED for CLI and sanctioned apps; UNVERIFIED for arbitrary unattended orchestrators.**
   - Codex is included in Free, Go, Plus, Pro, Business, Edu and Enterprise. The pricing page lists "Codex SDK, `codex exec`, and scriptable workflows" and local scheduled tasks for Plus/Pro/Business/Enterprise ([pricing](https://learn.chatgpt.com/docs/pricing)).
   - Since DevDay on 2026-09-29, "eligible ChatGPT Plus and Pro subscribers" can use their plan in supported apps ([SIWC doc](https://learn.chatgpt.com/docs/sign-in-with-chatgpt), [DevDay](https://learn.chatgpt.com/docs/whats-new/devday-2026)). Partners include OpenCode, OpenClaw, Pi, T3 and Conductor. Usage "counts toward your existing plan limits", with optional per-app weekly caps. Plan usage is available to "open-source partners and selected private clients"; commercial sign-in is a "limited trial". Open-source apps can register through [token sharing](https://developers.openai.com/siwc/token-sharing-open-source).
   - The [auth doc](https://learn.chatgpt.com/docs/auth) says "API keys are still the recommended default for automation". It documents copying `~/.codex/auth.json` to headless hosts.
   - No page read explicitly permits or forbids an unregistered orchestrator running `codex exec` unattended under a Plus/Pro login.
5. **Paperclip execution policy escalates after three agent revision rounds; Team Catalog and export/import exist — CONFIRMED.**
   - The default limit is three consecutive agent change requests, configurable via `maxReviewRounds` (1–50). The issue then goes to the responsible human or, if none is set, its creator. If neither exists, work returns to the implementer ([execution policy](https://docs.paperclip.ing/guides/power/execution-policy/)).
   - [Team Catalog](https://docs.paperclip.ing/guides/org/team-catalog/) is a set of versioned starter teams including routines.
   - [Export/import](https://docs.paperclip.ing/guides/power/export-import/) produces Markdown packages and never exports secret values.

## 3. What this means (uncertainty explicit)

- **H2 (subscription premise):** OpenAI is supportive, but routes third parties through registered SIWC and recommends API keys for automation. Anthropic tolerates subscription use of SDK/`claude -p`/third-party apps *today* only through the unmodified binary and own-login pattern. Its policy changed five times in eight months. Any AS candidate whose economics rest on Claude Max must treat a further reversal as likely (judgment, medium confidence). Pooling or rotating multiple consumer accounts is off-limits for Anthropic.
- **AS01 (adaptive model/effort controller):** The niche is real but not empty. Paperclip exposes model/effort per agent but no documented per-run model hook upstream. An upstream plugin can observe `agent.run.completed` and recommend; whether it can safely rewrite agent config is unverified. Model Capacity already targets "pick model+effort per run" deterministically. Hydra and Ruflo claim learned routing (unverified). **Residual gap:** a policy learned from the user's own verifiable outcomes (tests, review rounds, retries) per task type, with evidence and a shadow→enforce path. Platform risk: alpha SDK, and upstream or the Model Capacity author could ship the same thing. Confidence medium.
- **AS08 (quota-aware failover + checkpoints):** Strongest demand signal in this pass. Four open Paperclip requests since March 2026 are corroborated by data (#11597: 160/400 runs wasted), several forks, and Flock hand-building the pattern. OpenClaw proves ordered failover with subscription profiles works for assistants. **But** Paperclip may merge PR #9367 at any time, which would turn a venture into a contribution. **Residual gap:** gating on parsed reset times, treating budget denials as stops not fallbacks (a [#2743 comment](https://github.com/paperclipai/paperclip/issues/2743) makes this point), and semantic task handover across providers beyond branch state. The gap is likely small and plugin- or upstream-sized. Confidence medium.
- **AS07 (cross-provider routines dashboard):** Weakest. Paperclip, Tutti, Agency, Hermes, OpenClaw and Agno already schedule jobs across providers within their own runtime. First-party routines (Claude, Codex) are siloed, and no public list/read API was found for either, so a unified view of *first-party* routines is blocked rather than merely unbuilt. This is likely a feature of AS01/AS08, not a venture. Confidence medium-high.
- **AS05 (adaptive AI OS for technical teams):** The "team OS" layer is occupied by Paperclip (99.1k stars, Team Catalog, export/import, execution policy), Gas Town, Orchestrator.inc, Ruflo and Symphony. The framework substrate is occupied by LangGraph, Mastra, Agno and CrewAI. Its only differentiator would be the adaptive layer, i.e. AS01/AS08. Vibe Kanban's shutdown ("couldn't find a business model") and Conductor's cloud/collaboration pricing suggest monetisation sits in hosted collaboration, not orchestration. Recommendation input: merge AS05 into AS01/AS08 or drop. Confidence medium.
- Not verified here: maintainers' intentions for #9367, plugin SDK write access to agent model config, Paperclip adoption beyond stars, and real reliability of any tool (nothing was run).
