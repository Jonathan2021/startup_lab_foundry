# Additional bounded incumbent comparison: GPX inspection

Frozen before the attempt. Date: 2026-10-02. This is a synthetic public-coordinate
comparison, not the user's historical ride or a prediction-accuracy test.

Hypothesis: existing gpx.studio can display two different GPX paths at once and
preserve their geometry on import, removing the need for a generic new visual
comparison utility. RouteConverter documents format conversion and multiple
visible position lists; this is additional documentary counterevidence.

Fixture: two explicitly synthetic three-point GPX tracks around public Berlin
coordinates, with one displaced middle point. No personal travel data, timestamps
or estimated arrival times. No account, save/share/publication or payment.

Budget: one gpx.studio visit, inspect file input, import two fixtures if available,
maximum five minutes. Record names/visible paths and interface output/screenshot.
Stop at access/harness failures; they do not prove a missing product feature.
Do not install a separate desktop app just to repeat an already available visual
baseline. Success weakens a general compare/convert product premise; an automatic
explanation of cross-app recomputation remains a different, unvalidated job.
