# Foundry local operation and next venture investigations

Date: 2026-10-02. Frozen before the new implementation and trials.
User priority: Foundry usefulness and viable ventures; learning/slices paused.
Training and model downloads deferred. Local edits, UI and research authorized;
paid calls, outreach and publication require separate exact approval.

## Hypotheses and bounded checks

H1: a cwd-independent SQLite store, list commands and a browser view make existing
records usable without reconstructing paths or IDs from chat. Verify default path
across cwd, preserve prior databases, safely back up, import with stable identity,
and recover the same records after process restart.

H2: small typed steps can execute useful internal checks while retaining their
input/output and failure state. Check deterministic readiness and research briefs,
repeat-submission idempotency, cross-venture isolation, and a missing agent setup.
No readiness check establishes commercial viability. No automatic outreach.

H3: new ideas derived from specific unresolved jobs can be compared cheaply before
building. Record parent ideas and why an incumbent does not yet answer the question.
Compare a GPX handoff diagnostic, a source-change review queue, and a portable
work-sample receipt against existing utilities/services. Use at most three primary
competitors per narrowed job this round. Stop a broad build claim if a configured
incumbent already supplies the job; otherwise identify a reproducible test or
specific missing access. Vendor claims alone cannot pass a commercial gate.

## Acceptance before implementation

- CLI lists ventures, ideas, sources, steps, and venture-scoped existing records.
- UI browses persisted ideas/ventures/evidence/decisions and creates an idea or venture.
- UI/CLI start a step and show a durable outcome or explicit blocked state.
- Immutable input and runner/version context remain available for later review;
  no fine-tuning, automatic training capture or learner work is implied.
- The default SQLite path is stable across launch directories. Backups refuse to
  overwrite. Existing realignment/campaign stores remain intact.
- CSV import retains all rows/provenance, deduplicates generated-tab views, and
  does not execute attachment instructions or trust attachment competitor claims.
- Human intervention items are readable/editable files with exact next inputs.
- UI is loopback-only with escaped output and protected mutations; no cloud deploy.
- Meaningful local tests, browser task checks, lint/type checks and migration checks.

## Stop conditions

No accounts, payments, model downloads, external messages or publication. Record
missing route files/preferences, operator/issuer access, and model setup in requests
instead of repeatedly asking in chat. Continue independent checks. Failed access
or harness behavior is inconclusive, never evidence of a competitor deficiency.
