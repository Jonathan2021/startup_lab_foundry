## Combination rule

Do not combine X-001/X-002/X-003 into a universal evidence platform merely because
they all use the word evidence. They have different buyers, source guarantees,
privacy constraints, error costs and onboarding. A reusable primitive might
eventually emerge, but one must first work in two actual independently useful
workflows. Their current commonality is a research lead, not a product boundary.

## Source reuse policy

`sources.json` stores compact paraphrased claims, URLs, checked dates, evidence
type, limitations and refresh rules. `ideas.json` links consumers. Consult the
register before another search; reuse only the proposition the source supports.
Check volatile pricing/access within seven days and features within thirty days
or before an investment decision. Pinned trial artifacts retain their versions
even when vendor docs move. Never overwrite an old negative result as success.

This is a usable campaign convention, not an automatic freshness service. T3's
stale/unknown-source checks used explicit synthetic controls. No claim is made
that stale web content is now detected automatically or that measured tokens or
human time were saved. Hindsight has no local Ollama endpoint/binary available in
the checked environment, remains uninstalled, and was not benchmarked.
