## Gates and honest coverage

Each original record gets an explicit disposition, rationale, relevant source
links, uncertainty and next falsifying step. Group research by actual workflow,
then apply the result individually; never label a category-wide source an exact
competitor test for every idea in it. An access/safety/physical-data constraint can
justify an early hold without a runtime trial; record that distinction.

Use these evidence levels separately: source assertion, verified documentation,
component trial, end-to-end tool trial, first-party workflow observation,
independent customer observation, paid/adoption outcome. Website marketing is
not a passed trial. Synthetic cases test mechanics, not prevalence or accuracy
on real customer data. No score is a probability of business success.

Initial triage gates: permissible/trustworthy use; accessible workflow and data;
specific value beyond incumbent plus configuration/script; manageable trial;
plausible buyer/distribution; learning fit only as a tie-breaker after utility.
Record score/rule versions and before/after changes. Do not tune weights to crown
a favorite. Repeated generated ideas or one vendor's many feature pages are not
independent observations. Leave confidence low where demand is unknown.

## Practical trial queue, criteria fixed before execution

1. **EvalOps / evaluation datasets / experiment records:** exercise a pinned
   local MLflow installation if feasible in an isolated environment. Use synthetic
   non-sensitive data and deterministic checks. Attempt a trace, human feedback,
   a reusable evaluation record and failure/pass gate. Record which functions
   actually ran; no LLM calls. Stop setup at 15 minutes. A working incumbent
   weakens generic platform differentiation, not every specialist workflow.
2. **Monitoring / regulatory change / used-asset changes / document freshness:**
   inspect and, if locally feasible within 15 setup minutes, run an existing
   open-source change-monitor on controlled local content. Test a meaningful
   change and irrelevant noise against configured selection/ignore behavior.
   No customer sites, authenticated content, real notifications or paid services.
   Distinguish tested component behavior from full platform operation.
3. **Source reuse across venture decisions:** reuse a compact canonical source
   index and exact claim references for at least three genuinely different idea
   groups. Compare provenance recovery with existing `rg`/SQLite tooling; record
   exact retrieval outcomes and repeated source uses. This is a mechanical
   provenance test, not a human-time or semantic-memory superiority benchmark.
   Hindsight remains optional; check local availability without paid fallback.
4. **Additional survivors:** first use public documentation/demos or local
   permitted inputs to try to falsify their distinguishing claim. If a test needs
   private data, physical equipment, interviews, an account or payment, retain an
   exact access blocker and next action. Do not invent a successful trial.

Freeze more specific inputs/versions/assertions before each executable trial.
Failed setup remains recorded. Keep paid/API/hosting spend at zero. No outreach,
account creation, publication, purchases, financial action or physical/medical
experimentation is authorized. Read-only public research and local reversible
software work are authorized. Do not inspect private financial accounts.

## Foundry evolution and completion boundary

Start with existing application operations and plain local campaign records.
Reuse source records manually before building a research cache. For each possible
capability, retain at least two distinct operational occurrences, the workaround,
and the smallest behavior that resolves them. Implement only a demonstrated need
within this campaign; meaningful acceptance tests precede a runtime change.
Keep shared-library extraction conditional on independently recurring needs.

Deliver a complete intake/disposition register, source/claim index with refresh
rules, actual trial results, calibration revisions, cross-idea gap hypotheses,
Foundry evidence/decision records and a short surviving queue. A completed first
pass does not mean every idea received a runtime or demand test. If no candidate
earns commercial-build status, say so and retain exact blockers; do not manufacture
a mature venture to satisfy a quota. Customer-independent discovery cannot prove
willingness to pay. Campaign continuation must identify the next evidence needed.
